Automatically scrape HR/recruiter emails from LinkedIn job postings and auto-email them when new positions open. Run the CLI command below, then come back here to see scraped contacts and add them to your email campaign.
# Scrape HR emails from LinkedIn
node automation/runner.js scrape-hr
# Monitor & auto-email when new jobs post
node automation/runner.js scrape-hr --monitor
# Target a specific company
node automation/runner.js scrape-hr --company "Razorpay"

🤖 Automation
Run the automation from your terminal to schedule daily/weekly job applications.
# First-time setup
node automation/setup.js
# Full run (analyze + email + fill)
node automation/runner.js run
# Scrape HR emails from LinkedIn
node automation/runner.js scrape-hr
# Monitor & auto-email new jobs
node automation/runner.js scrape-hr --monitor
# Schedule daily at 9 AM
node automation/runner.js schedule --daily 09:00
# Auto-fill Naukri forms
node automation/runner.js fill --site naukri
Edit profile.json + .env before running.
